# EYESOFPRIESTESS（EYESOFPRIESTESS）方案 v1

> 日期：2026-11-13 ｜ 状态：定稿，待开工
> 一句话定位：**给 human-v1.0 装雷达**——实时识别战场上的敌人位置/身份/数量，人是决策核心，机器只补人眼的短板。

---

## 0. 定位与范围

### 做（MVP = L1 雷达辅助）
- 实时 overlay：敌人/友军位置、身份、数量、血条，带 track 编号
- 后台自动录帧 + 存场景图，**每局实战都是数据采集**
- 为 RTAS（朋友的整体工程）输出标准场景图 JSON

### 不做（本期明确排除）
- 自动战斗决策逻辑（L2-L4，另立项，见下方阶梯）
- 整帧透视矫正 / warp（会撕裂角色，见 1.2）
- 单帧直接读逻辑状态（动画优于逻辑，见 1.3）
- 让 AI 或群友"认碎片"（身份判别只在最佳帧做，见 3.2）

### 成熟阶梯
    L1 雷达辅助   <- 本期目标。overlay 显示，人坐在前面打
    L2 建议模式   overlay 加"该开技能/要漏怪"提示，人定夺
    L3 半自动     人标部署位，ADB 执行层替人点
    L4 全自动     状态机上，human-v1.0 退居仲裁

L2-L4 全部消费同一份场景图 JSON，接口在实战中打磨，插入时零返工。

## 1. 架构总纲

    OBS 录像 -> extract_frames -> 标注(LS) -> clicks JSONL -> SAM出框 -> YOLO 数据集
                                                                     |
    屏幕捕获 -> YOLO检测 -> ByteTrack -> 场景图 JSONL <---------------+
                                            |
                        RTAS 后处理（单应/tile 映射/决策）-> 雷达 overlay

### 1.1 三层职责（今晚三次纠错后的最终版）

| 层 | 职责 | 关键约束 |
|---|---|---|
| 视觉层 | 检测、身份匹配、跟踪 | 全程纯像素坐标，对"格子"零感知；永远跑原图，一行 warp 都不写 |
| 逻辑层（RTAS） | 单应标定（每图 4 角点）、tile(i,j)<->像素映射、格子吸附、部署决策 | 换地图=换一组单应参数，数据与模型不动；标定漂移重拟合不回溯标注 |
| 状态层 | 逻辑状态判定 | 只吃 tracklet 事件+时间聚合，不吃单帧分类 |

### 1.2 为什么不 warp
明日方舟地面按 3D 透视投影，角色是不按透视缩放的 2D 序列帧——两者不共享同一投影约束，任何整帧矫正必然撕裂一类像素。透视不被修正，被绕过：它是 RTAS 映射表里的参数，不是图像上的操作。

### 1.3 为什么状态层不吃单帧
死亡动画不等于离场、出场动画不等于未入场、特效会整帧盖住血条。单帧视觉状态不等于逻辑状态，故一切单帧异常按噪声滤掉，由时间聚合吸收。

## 2. 数据管线（项目的核心资产）

    录: OBS 原片直录（禁 B 站二压），锁分辨率，每图录平推局+高压局约 7:3
    抽: extract_frames.py（感知哈希+帧差去重、限流防特效刷屏、原分辨率输出）
    标: Label Studio（KeyPointLabels 点选，A/S/D/F 类别键，G/H ignore）
    转: ls_export2clicks.py（百分比转像素、IGNORE-* 映射 type:ignore）
    框: nightly 点->SAM 出精确框；ignore 点出 ignore 区域
    训: YOLO 格式导出 -> train_yolo.sh

### 2.1 标注规范（人类智慧的工程化）
1. 人只点选，绝不画框。框是 SAM 的派生物。
2. 一轮一类，类别集合按关卡给，键位一只手够按。
3. 碎片一律 ignore（G=occluded，H=blurry）：标 type:"ignore" 保留坐标与"此处有不可判定目标"的事实，不悄悄删帧——悄悄删会让数据集对密集怪群产生系统性盲区。
4. ignore 率是健康指标：某类图 ignore 率飙升 = 该补采了。
5. 多标注人共存，同帧多份点击按投票/专家裁决合并；分类器在最清晰帧仍 top-2 犹豫的样本进专家队列——全数据集单位价值最高的样本。
6. 身份不在遮挡帧判：tracklet 最佳帧裁全身做匹配，标签沿轨迹回写。

### 2.2 点击 schema（系统地基，锁定）
    {"frame":"v001_f004213.png","x":512,"y":384,"cls":"源石虫","type":"point","op":"dhjs0000","uid":"...","ts":...}
    {"frame":"v001_f004213.png","x":640,"y":150,"cls":null,"type":"ignore","reason":"occluded","op":"...","uid":"...","ts":...}

append-only JSONL，只增不改，可回放可审计。所有环节消费它。

## 3. 模型配置

### 3.1 检测：YOLOv8s @1280
- 小目标三件套：imgsz=1280（源石虫 40px，640 直接蒸发）、freeze=10 冻 backbone 防小数据过拟合、mosaic 拉满
- copy-paste 离线做（offline_copypaste.py），按目标 tile 的透视尺度缩放——单应参数从 RTAS 取，贴第 4 排的虫自动比第 1 排小
- COCO 预训练起步；导出 TensorRT fp16（4060 上 1280 输入三位数 FPS，决策环只要 5-10）
- 粗类：enemy / ally
  - 玩家干员不标（部署位置 RTAS 侧已知）；`ally` = 可自由移动的非玩家友方单位（友军 NPC、召唤物），才是雷达要补的未知量
  - 血条不进检测类别：半透明黑底 + 纯色填充，CV 颜色阈值直接拿，模型学它只会引入噪声（受击/技能会变色）
- 备选（撞墙后再换）：RT-DETR-L / PP-YOLOE+

### 3.2 身份：embedding 图库匹配，不训分类器
- ConvNeXt/CLIP 编码裁剪图 -> 与 PRTS 官方图库参考向量最近邻
- 新敌人上线 = 图库加 5-10 张参考图，零训练接入——这是对抗"维护成本"这个核心敌人的主武器
- top-2 距离过近 -> 专家队列（人类细粒度判断当前仍碾压 AI，已实战验证）

### 3.3 跟踪：ByteTrack
逐帧框连成 tracklet；兼作"最佳帧身份裁决"的执行者。所有状态消费 tracklet 事件。

### 3.4 评估集（自建，最高优先级）
- 手标 GT 两帧起：干净帧（模拟器直出）+ 难帧（暗色/密集/遮挡，金骑士列案例）
- 每训一个版本先在这两帧上报数：错一个虫、误一个兵、数错一个重叠个体，当场现形
- 干净帧 AI 已与人类打平；难帧承认差距，用 ignore + 最佳帧裁决兜住

## 5. 里程碑与验收

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M0 数据采集 | 装 OBS，录 1-7/1-8 各数段（含高压局），抽帧，LS 标首批 300-500 点击 | 帧入 LS，导出转换零 skip |
| M1 v0 检测器 | YOLO@1280 首训 | GT 干净帧报数：无漏检、误检不超过 1 |
| M2 雷达上线 | predict_track 接 overlay（渲染属 RTAS 侧），实战录帧回流 | 打一局，overlay 与肉眼基本一致；难帧不怪系统（已标 ignore） |
| M3 飞轮转动 | 每局自动入库、主动学习挑低置信帧、LS 复审、v1 | ignore 率稳定，新 SS 上线 48h 内接入图库 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 小目标漏检 | 1280 输入 + P2 头（必要时）+ 高分辨率切片 |
| 同类重叠重复计数 | tracklet 时序去重 + 最佳帧裁决；评估集专门设重叠 case |
| 异类相似外观误判 | embedding 图库 + top-2 专家队列，不靠单帧碎片 |
| 特效/动画污染 | 状态层时间聚合；单帧异常一律当噪声 |
| 标注供给不足 | LS+群友点选（选择题而非创作题），碎片 ignore 降低难度 |
| 平台 friction | LS 撑到 v1，群友被注册劝退则启用自研页（schema 不变） |
