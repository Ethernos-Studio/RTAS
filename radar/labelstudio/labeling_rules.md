# 标注规矩（点选 / ignore 判定）

一句话：**能确定"是谁、在哪、是一个独立目标"，就点编码；确定不了才 ignore。**

## 一、两种 ignore 的判定线

**IGNORE-occluded（遮挡）** —— 满足任一条就用它：
- 目标可见部分不足 2/3；
- 目标中心点被别的物体/特效盖住；
- 两个目标叠在一起，分不出各自边界（框没法归给某一个）；
- **敌人贴着/被干员挡住时更严**：只要干员的身体盖住敌人的 1/3 以上，就标 `IGNORE-occluded`。
  原因：点选 + SAM 在这种情况下很难只框住敌人，框里会混进干员——那是**坏样本**，
  比少一个正样本更糟（模型会学着把干员框进敌人里）。

典型：干员挡住敌人、两个源石虫叠成一坨、可放置障碍物压住半个身子。

**IGNORE-blurry（模糊）** —— 满足任一条就用它：
- 在当前分辨率下看不出兵种特征（刀兵和源石虫都分不清）；
- 目标小于约 20px 且边缘发糊（拖影/压缩），点下去也定不住位置。

典型：技能特效整片罩住、快速移动拖影、录屏二压糊成一团。

判定顺序：先看能不能认出兵种，再看出没出边界。
认不出兵种 → IGNORE-blurry；认得出但边界被盖/重叠 → IGNORE-occluded。

## 二、这些情况不要 ignore（最常见误标）

- **受击变红 / 闪白**：照常点编号。颜色是受击反馈，不影响"是谁"，SAM 照样能框住。
- 释放技能、身上有光效但本体可见：照常点编号。
- 目标很小（10~20px）但轮廓清楚：照常点编号（这正是 imgsz=1280 要保的东西）。
- 死亡动画刚放倒、还能看出是敌人：照常点；已化成烟尘/碎块 → IGNORE-occluded。
- 屏幕边缘被裁掉一角：主体在画面内、能认出兵种 → 照常点；只剩一小角 → IGNORE-occluded。
- 认得是敌人但编号对不上：点 other_enemy（b），不要 ignore；编号回头补进 configs/enemies.json。
- 目标被自己的血条/图标压住一点：照常点编号。

## 三、编号是**按关卡**的（别跨关套码）

图鉴里的编号和"这一关出什么敌人"绑定，不同关卡不通用：

- 1-8 只有 `02`，没有 `01`；
- 1-9 只有 `01`，没有 `02`。

所以标注时**以当前关卡的图鉴/画面为准**，不要因为"长得像上一关那个虫"就套同一个码。
拿不准就点 `other_enemy`(b)，回头告诉我，我用 `radar add-code` 补进来。

## 四、场景物（路障 / 装置 / 木箱）一概不标

能交互的只有路障、装置那几种，而**它们的位置在游戏的地图数据里本来就有**（RTAS 侧直接读得到），
模型去学它既没有收益、又会把地图装饰（成堆木箱、货架、桶）误报成装置。

所以：**任何不动的场景物都不点**——路障、装置、箱子、地面格子、地图装饰、关卡 UI 一律跳过。
只点会动的**单位本体**：敌人点图鉴编号；**非玩家友军点 lly**
（例如第八章的斗士塔鲁拉——它会自己跑，位置未知，正是雷达要补的）。

## 五、三只叠成一条（01 / 21 / 01 上下叠）

这种"上中下叠在一起"的情况按**各自的可见程度**分：

- 三个都能看出本体（至少看得到自己的头和身体轮廓、中心没被盖死）→ **三个都点各自的编号**，
  点在**各自身体中心**上，别点在交叠处；
- 中间那个只露出一小条、中心被上下夹住 → 它打 `IGNORE-occluded`，上下两个照常点；
- 上下两个也被压掉一半 → 也只给看得清的那个点编号，其余 ignore；
- 整帧糊成一团（谁是谁都分不出）→ 整帧 Skip，比点一堆 ignore 更划算。

**别因为"叠在一起"就整帧跳过**：这类重叠样本正好是修"两个怪合成一个框"最有用的数据，
能标就标。标完之后框会越来越准。

同理，**两个刀兵前后叠**：两个都能看出自己的头/身/腿 → 各点各的编码；
后面那个只剩一条边、认不出轮廓 → 它打 `IGNORE-occluded`，前面那个照常点。

## 六、血条、技能条：一概不标

这两种条长得一样：**半透明黑底 + 彩色填充**（没有白色填充），干员和装置身上都有。

- **血条**：红色（敌）/ 蓝色（友）填充。**不标**——它是简单图形，CV 颜色阈值直接拿，
  让模型学只会引入噪声（干员开技能时血条会变红，同类不同色，学出来是假规律）。
- **技能条**（更细、贴在血条下面）：绿色 = 充能中或已就绪，橙色 = 技能生效中。**不标**——
  它是状态，不是目标，状态判断交给时间聚合（HANDOFF §1.3）。

所以：看到任何"条"，都不要点。你只需要点**单位本体**和**装置本体**。

## 七、两个数值锚点

- 遮挡线：可见约 2/3 以上就照常点；低于 2/3 或中心点被盖才 IGNORE-occluded。
  （框由 SAM 出，遮住 1/4 以内基本不影响框质量。）
- 模糊线：能分辨轮廓与主色就照常点；连"这是不是源石虫"都要犹豫，才 IGNORE-blurry。

## 八、口诀

颜色、特效、小目标 → 照常点；
认不出是谁 → blurry；
边界被盖或重叠 → occluded；
只是编号不认识 → other_enemy；
不动的场景物 → 不标（路障也不标）；
**任何血条、技能条 → 都不标**。

## 九、数量上的提醒

- 一帧里 ignore 不应超过 1/3。超了说明这帧不适合当样本（特效糊屏、大团重叠），直接 Skip 整帧更划算。
- ignore 率是健康指标：某类图 ignore 率飙升 = 该场景没录够，要补采，不是标注变懒。

## 十、为什么要这么严

ignore 记录的是"此处有目标但不可判定"这个事实（坐标准确、类别留空），它不进训练集，
但会留在 dataset/labels_ignore/ 供复查。随手 ignore 会让数据集对密集怪群产生系统性盲区；
把能认的目标误标 ignore，等于亲手把这个样本从训练集里删掉。
